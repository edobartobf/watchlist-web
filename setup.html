🎬 Configurazione

Qui cifri i token con la master password e generi config.js. Tutto avviene nel browser: niente viene inviato da nessuna parte tranne le due chiamate di verifica a GitHub e TMDB.

1. Repository dei dati

2. Token

  1. GitHub → Settings → Developer settings → Fine-grained token: solo il repo dei dati, permessi Contents: Read and write e Actions: Read and write (per «Controlla ora»).
  2. TMDB → Settings → API: «API Read Access Token».

3. Master password

config.js è pubblico: chi lo scarica può provare password a ripetizione. Usa una frase lunga (almeno 4–5 parole).

4. Pubblica

Sostituisci config.js nel repo della pagina con questo contenuto, poi fai commit e push.
